# Turnos de consulta medica (simple)

- `app.py`: configuracion, base de datos, modelo (funciones) y controlador (rutas).
- `views/`: paginas HTML (plantillas de web.py). `layout.html` es la base de todas.

## Correrlo

Linux / Mac / Codespaces:  `bash iniciar.sh`
Windows:                   doble clic en `iniciar.bat`

Abre http://localhost:8080
